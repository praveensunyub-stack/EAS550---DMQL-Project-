# AI Use and Accountability

## AI Tools and Purpose

We got some assistance from AI in case we encountered some errors in our program and needed to get help to correct them.

The development of the database design, coding, and testing of our project was done by our team. The major use of AI in our case was in error understanding and correction suggestions.

## Prompt Summaries

1. We asked AI to clarify the errors that occurred during the execution of our Python code for data verification and loading.
2. Moreover, we sought advice from AI to solve the testing errors and interpret the outcomes of our verification tests.

## Testing and Verification

We evaluated the suggestions provided by AI before proceeding with any modifications. We performed a code and SQL query review, made the necessary adjustments, and re-ran the test to ensure that all is good.

We also performed a database row count evaluation, table relationship evaluation, and data load evaluation to ensure that there are no problems.

It is our responsibility as a group of three to comprehend the code, SQL query, database design, and the results that we have submitted.
